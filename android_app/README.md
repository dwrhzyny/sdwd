# Productivity Gate - Android

אפליקציית אנדרואיד: כשפותחים אותה היא שואלת אם סיימת את המשימות של היום.
אם לא סיימת - כל אפליקציה שהגדרת כ"חסומה" תיסגר אוטומטית ותוחזר למסך חסימה
ברגע שתנסה לפתוח אותה, עד שתסמן שסיימת. אפשר גם להגדיר טיימר יומי (בדקות)
לכל אפליקציה בנפרד.

## למה זה עובד ככה באנדרואיד

באנדרואיד אין דרך "רגילה" (בלי הרשאות מיוחדות) לחסום אפליקציות אחרות.
הדרך התקנית לעשות את זה היא **Accessibility Service** - שירות נגישות שמזהה
איזו אפליקציה פתוחה כרגע, ואם היא ברשימת החסימה - מציג מסך חסימה. זו הדרך שבה
עובדים גם אפליקציות מסחריות כמו Forest, One Sec, StayFree וכו'.

## הדרך הכי קלה: לבנות APK בענן עם GitHub Actions (בלי להתקין כלום)

הפרויקט כבר מוכן עם הגדרות בנייה אוטומטיות. ככה תקבלו קובץ APK מוכן להתקנה
בלי להתקין Android Studio בכלל:

1. פתחו חשבון חינמי ב-https://github.com (אם אין לכם).
2. לחצו **New repository**, תנו שם (למשל `productivity-gate`), Public או
   Private - לא משנה, ולחצו **Create repository**. אל תסמנו "Add a README".
3. בעמוד הריפו החדש, לחצו על הקישור **uploading an existing file**.
   גררו לתוכו את **כל התוכן** של התיקייה שחילצתם מה-zip (כולל התיקיות
   `app`, `gradle`, `.github` וכל שאר הקבצים), ולחצו **Commit changes**.
4. עברו ללשונית **Actions** בראש העמוד. אמור לרוץ אוטומטית workflow בשם
   "Build APK" (אם לא - לחצו עליו ואז **Run workflow**).
5. חכו כ-5-10 דקות עד שתראו סימן \u2713 ירוק.
6. לחצו על ההרצה שהסתיימה, גללו למטה לאזור **Artifacts**, והורידו את הקובץ
   (zip שמכיל את ה-APK). חלצו אותו.
7. העבירו את קובץ ה-APK לטלפון (מייל לעצמכם, גוגל דרייב, כבל USB וכו'),
   פתחו אותו על הטלפון ואשרו התקנה (יתכן שיהיה צריך לאשר פעם אחת
   "התקנה ממקורות לא ידועים" בהגדרות).

זה APK מסוג "debug" (חתום אוטומטית במפתח פיתוח על ידי Gradle) - מתאים
לשימוש אישי לגמרי, פשוט לא מיועד להעלאה ל-Google Play.

אם משהו נכשל בלשונית Actions (X אדום) - תלחצו על ההרצה כדי לראות את
הלוג המדויק, ותוכלו להעתיק לי את השגיאה.

## או: לפתוח ולהריץ עם Android Studio

הפרויקט בתוך ה-zip הוא כבר פרויקט Gradle שלם ועצמאי - אין צורך ליצור
פרויקט חדש ולהעתיק קבצים:

1. התקינו Android Studio (חינמי): https://developer.android.com/studio
2. **File -> Open**, ובחרו את התיקייה שחילצתם מה-zip (זו שיש בה את הקבצים
   `settings.gradle.kts` ו-`app`).
3. תנו ל-Android Studio זמן לבצע **Gradle Sync** (זה מוריד אוטומטית את כל
   מה שצריך - דורש חיבור אינטרנט על המחשב שלכם, לא באפליקציה עצמה).
4. לחצו **Run** \u25b6 על מכשיר אנדרואיד אמיתי (מחובר בכבל USB עם "ניפוי
   שגיאות USB" מופעל) או על אמולטור.

## שלב 2: הגדרת האפליקציה

בפתיחה הראשונה תראו את מסך המשימות עם 3 משימות ברירת מחדל. לחצו על
"הגדרות: אפליקציות חסומות וטיימרים" כדי:
- להוסיף/לערוך את המשימות היומיות שלכם.
- להוסיף אפליקציות לחסימה (צריך את ה-**package name** שלהן - ראו טבלה למטה).
- להוסיף טיימר יומי (בדקות) לכל אפליקציה.

לאחר מכן חזרו למסך הראשי ולחצו **"הפעל הרשאת נגישות"**. זה יפתח את הגדרות
האנדרואיד - חפשו שם "Productivity Gate" ברשימת השירותים והפעילו אותו.
**בלי השלב הזה החסימה לא תעבוד בכלל** - זו ההרשאה שמאפשרת לאפליקציה לדעת
איזו אפליקציה פתוחה כרגע.

## package names נפוצים לדוגמה

| אפליקציה | package name |
|---|---|
| Chrome | com.android.chrome |
| Instagram | com.instagram.android |
| TikTok | com.zhiliaoapp.musically |
| YouTube | com.google.android.youtube |
| Facebook | com.facebook.katana |
| WhatsApp | com.whatsapp |
| Twitter/X | com.twitter.android |

אם אתם לא בטוחים לגבי אפליקציה מסוימת - אפשר לחפש את שמה + "package name" בגוגל,
או להוריד אפליקציה חינמית כמו "Package Name Viewer" מ-Google Play שמציגה את
שמות החבילה של כל האפליקציות המותקנות אצלכם.

## סנכרון עם המחשב (Windows)

אפשר לגרום לרשימת המשימות ולסטטוס "סיימתי היום" להיות משותפים בין הטלפון
למחשב, כך שאם תסמן שסיימת באחד מהם - זה ישתקף גם בשני. **אפליקציות חסומות
וטיימרים נשארים נפרדים לכל מכשיר** (כי שמות האפליקציות שונים בין אנדרואיד
לווינדוס ממילא).

הסנכרון עובד מול Firebase Realtime Database (שירות חינמי של גוגל):

1. גשו ל-https://console.firebase.google.com/ והתחברו עם חשבון גוגל.
2. **Add project** -> תנו שם (למשל "productivity-gate") -> אפשר לכבות
   Google Analytics -> **Create project**.
3. בתפריט הצד: **Build -> Realtime Database -> Create Database**. בחרו מיקום,
   ובשלב חוקי האבטחה בחרו **Start in test mode**.
4. אחרי היצירה, עברו ללשונית **Rules** ושנו את החוקים לכך שיישארו פתוחים
   (מצב הבדיקה נסגר אוטומטית אחרי 30 יום):
   ```json
   {
     "rules": {
       ".read": true,
       ".write": true
     }
   }
   ```
   **שימו לב:** זה אומר שכל מי שיודע את הכתובת המדויקת שלכם יכול לקרוא/לכתוב
   אליה. זה סביר לפרויקט אישי כזה, אבל אל תשתפו את הכתובת עם אף אחד.
5. למעלה בעמוד ה-Realtime Database תראו כתובת בסגנון
   `https://productivity-gate-XXXXX-default-rtdb.firebaseio.com` - זו הכתובת
   שצריך להזין בשני המכשירים.
6. באפליקציית האנדרואיד: הגדרות -> "סנכרון עם המחשב" -> הדביקו את הכתובת ->
   שמור. עשו את אותו הדבר בתוכנת הווינדוס (תפריט האייקון במגש המערכת ->
   "הגדר סנכרון עם הטלפון").

מרגע זה, כל הוספת משימה או סימון "סיימתי"/"עדיין לא" באחד המכשירים תישלח
לשרת, וכל מכשיר מושך עדכונים כשהוא נפתח (וגם ברקע כל כמה דקות).

## תזכורות

אם עד סוף היום לא סימנתם שסיימתם את המשימות, האפליקציה תשלח לכם התראה
מדי כמה זמן (בהגדרות -> "תזכורות" -> "דקות בין תזכורות"). שימו לב: בגלל
מגבלה של אנדרואיד על עבודות רקע תקופתיות, המרווח המינימלי בפועל הוא 15 דקות
(גם אם תזינו מספר קטן יותר). לחיצה על ההתראה פותחת את מסך המשימות.

## איך זה עובד מאחורי הקלעים

- `PrefsHelper.kt` - כל הנתונים (משימות, אפליקציות חסומות, טיימרים, סטטוס יומי)
  נשמרים ב-SharedPreferences, ומתאפסים אוטומטית בכל יום חדש.
- `AppBlockerService.kt` - שירות הנגישות. מזהה כל החלפת אפליקציה, ואם צריך
  לחסום - פותח את `BlockOverlayActivity`. גם סופר כל שנייה כמה זמן נעשה
  שימוש באפליקציות עם טיימר.
- `MainActivity.kt` - מסך המשימות היומי (כולל הוספת משימה מהירה).
- `SettingsActivity.kt` - ניהול משימות, אפליקציות חסומות, טיימרים, סנכרון ותזכורות.
- `BlockOverlayActivity.kt` - מסך מלא שמופיע במקום האפליקציה החסומה.
- `SyncManager.kt` - שולח/מושך משימות וסטטוס מ-Firebase.
- `ReminderWorker.kt` + `ReminderScheduler.kt` + `NotificationHelper.kt` - תזכורות תקופתיות.

## מגבלות לדעת עליהן

- זו אפליקציה לשימוש אישי (self-control), לא כלי הגנת הורים מלא - משתמש
  טכני יוכל לבטל את הרשאת הנגישות ידנית ולעקוף את החסימה.
- כדי שהחסימה תעבוד צריך שהאפליקציה תישאר מותקנת ושהרשאת הנגישות תישאר
  פעילה. חלק מהיצרנים (שיאומי, וואווי, סמסונג עם "אופטימיזציית סוללה") נוטים
  לסגור שירותי רקע - אם תבחינו שהחסימה מפסיקת לעבוד אחרי כמה שעות, כדאי לחפש
  בהגדרות המכשיר "הוצא את Productivity Gate מאופטימיזציית סוללה".
